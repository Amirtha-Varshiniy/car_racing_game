# Two Player Car Racing Game using Python Turtle

This project is a multiplayer car racing game developed using Python Turtle graphics.

## About the Project
The game was created as part of a Python learning course to understand game development concepts such as:
- Keyboard controls
- Real-time movement
- Collision detection
- Animation loops
- Multiplayer interaction

## Technologies Used
- Python
- Turtle Graphics

## Features
- Two-player gameplay
- Interactive controls
- Racing track interface
- Real-time animation

## Learning Outcome
This project helped improve my understanding of Python programming and basic game development techniques.
